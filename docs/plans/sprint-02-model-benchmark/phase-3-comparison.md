## 평가 메트릭 (6항목, 각 10점 만점)

| # | 메트릭 | 평가 기준 |
|---|--------|----------|
| 1 | 테이블 구조 정확도 | 행/열/헤더 계층이 GT와 일치하는가 |
| 2 | 병합 셀 처리 | colspan/rowspan이 정확히 표현되는가 |
| 3 | 간트 차트 해석 | 색상→상태 매핑이 GT와 일치하는가 |
| 4 | 정보 손실 | GT 대비 누락된 데이터가 있는가 |
| 5 | 가독성 | Markdown 시맨틱 마크업 품질 (볼드, 구분선 등) |
| 6 | 토큰 효율 | 입출력 토큰 대비 품질 비율 |
